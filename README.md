# Brazilian E-Commerce Data Analysis | Olist

## 1. Project Overview

This project focuses on exploring and analysing the Brazilian E-Commerce Public Dataset by Olist using Microsoft Power BI.

The objective is to understand the business performance of an e-commerce marketplace by examining customer behaviour, order trends, product performance, payment methods, delivery performance and customer reviews.

The project involves data understanding, data quality assessment, data cleaning, data modelling and interactive dashboard development to generate meaningful business insights and support data-driven decision-making.

### Project Objectives

- Understand the structure and relationships within the Olist dataset.
- Assess data quality and identify missing values, duplicates and inconsistencies.
- Clean and transform the data using Power Query.
- Develop a suitable data model in Power BI.
- Analyse sales, customer behaviour and delivery performance.
- Create interactive dashboards to communicate business insights.

### Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- GitHub (Project Documentation)
